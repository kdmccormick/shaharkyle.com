# Images

Drop a photo of the two of you here named **`us.jpg`** and it will appear
automatically in the `// us` section of the landing page.

- Path the page looks for: `public/images/us.jpg`
- Recommended: landscape-ish, at least 900px wide
- Until the file exists, the page shows a placeholder frame instead

To use a different filename or format, update the `src` on `#us-photo`
in `src/pages/index.astro`.
